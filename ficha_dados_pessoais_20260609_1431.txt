======================================================================
  MAPEAMENTO SUGERIDO: Campos do banco -> Atributos LDAP
======================================================================

  Campo no banco          -> Atributo LDAP          -> objectClass
  ----------------------------------------------------------------
  nome / nomeCompleto       -> cn / displayName          -> inetOrgPerson
  nome (primeiro)           -> givenName                 -> inetOrgPerson
  nome (sobrenome)          -> sn (surname)              -> inetOrgPerson
  cpf                       -> employeeNumber            -> inetOrgPerson
  rg                        -> custom: rgNumber          -> custom schema
  matricula                 -> employeeNumber            -> inetOrgPerson
  email                     -> mail                      -> inetOrgPerson
  telefone                  -> telephoneNumber           -> inetOrgPerson
  celular                   -> mobile                    -> inetOrgPerson
  endereco                  -> postalAddress             -> inetOrgPerson
  cep                       -> postalCode                -> inetOrgPerson
  cidade + uf               -> l (locality) + st         -> inetOrgPerson
  cargo                     -> title                     -> inetOrgPerson
  departamento              -> departmentNumber / ou     -> inetOrgPerson
  dataNascimento            -> custom: birthDate         -> custom schema
  dataContratacao           -> custom: hireDate          -> custom schema
  login                     -> uid                       -> inetOrgPerson
  senha                     -> userPassword              -> inetOrgPerson
  foto                      -> jpegPhoto                 -> inetOrgPerson
  banco/agencia/conta       -> NAO COLOCAR NO LDAP       -> manter no MySQL
  salario                   -> NAO COLOCAR NO LDAP       -> manter no MySQL
  dados saude               -> NAO COLOCAR NO LDAP       -> manter no MySQL (restrito)
  pai/mae                   -> NAO COLOCAR NO LDAP       -> manter no MySQL

  IMPORTANTE:
  - Dados financeiros (banco/agencia/conta/salario) NAO devem ir pro LDAP
  - Dados de saude NAO devem ir pro LDAP (LGPD Art. 5 - dado sensivel)
  - Dados de familia NAO devem ir pro LDAP
  - LDAP = identificacao + contato + cargo/departamento + autenticacao
  - MySQL = dados financeiros, saude, auditoria, historico
